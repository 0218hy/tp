AVAILABLE COMMANDS

Help
  help

Add client
  add-client n/NAME i/PHONE_NUMBER e/EMAIL a/ADDRESS [t/TAG]...

List clients
  list

Edit client
  edit INDEX [n/NAME] [i/PHONE] [e/EMAIL] [a/ADDRESS] [t/TAG]...

Find clients
  find KEYWORD [MORE_KEYWORDS]

Delete client
  delete-client INDEX
  delete-client i/PHONE_NUMBER

Add pet
  add-pet p/PET_NAME i/OWNER_IDENTIFIER s/SPECIES [b/BREED] r/REQUIREMENTS

Delete pet
  delete-pet p/PET_NAME i/OWNER_IDENTIFIER

Clear all entries
  clear

Exit
  exit
